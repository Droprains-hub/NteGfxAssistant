# 异环画质助手 · NteGfxAssistant

面向《异环》（Neverness to Everness）Android 版的 Root 级画质配置工具，以可视化界面替代手工编辑 Unreal Engine 配置文件。软件开源免费。

当前版本：**v1.5.1**（versionCode 151）

## 功能特性

- **多渠道支持**：官服 / 哔哩哔哩服 / 台服 / 国际服，自动识别安装状态并切换配置目录
- **画质参数可视化调节**：帧率、渲染分辨率、色彩分级等参数图形化配置，无需手改 ini
- **自定义画质档位**：视距、植被、贴图纹理、材质、后处理可逐项调整，不受整体预设覆盖
- **交通系统**：单独调节城市 NPC、行人与车流密度
- **ANF 补丁开关**：可一键注入 / 移除游戏的 ANF 二进制补丁（实验性功能，部分设备与游戏版本不支持）
- **Root 文件操作**：兼容 KernelSU / Magisk 等 su 环境，配置写入以原子替换方式进行并锁定只读
- **配置管理**：初始化、重写、一键恢复（同时还原 ANF 补丁）、运行日志导出
- **可选联网能力**：公告、更新检查（服务端未配置时静默降级，不影响本地功能）
- **界面**：Material Design 3 + 极光主题、中英双语、明暗模式

## 构建

环境要求：JDK 17+、Android SDK（compileSdk 36）、Gradle 8.13

```bash
# 调试构建
./gradlew :app:assembleDebug

# 发布构建（需自行配置签名）
./gradlew :app:assembleRelease
```

发布构建需自行配置签名，签名信息不入库。`tools/build-release.ps1` 提供完整的正式构建 + 签名校验 + 摘要计算流程。
